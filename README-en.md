- **Site Reliability Engineering (SRE):** Architecting self-healing and auto-scaling infrastructure. Implementing Observability practices (Prometheus, Grafana), RED metrics, and Chaos Engineering.

- **Software Engineering:** Full-stack development and microservices architecture design, applying OS and computer network principles in practice.
