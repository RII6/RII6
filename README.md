# Добрый день, я Альберт 👋

### DevSecOps Engineer | CyberSecurity Enthusiast

Я студент Университета Иннополис (направление CyberSecurity), специализируюсь на интеграции безопасности в процессы CI/CD, защите облачной инфраструктуры (Kubernetes) и управлении уязвимостями. Строю процессы от проверки кода до мониторинга в рантайме.

## 🎯 Мой фокус в DevSecOps
- **Securing Infrastructure & Cloud:** проверяю Terraform и Ansible с помощью **Checkov/KICS**, хардэню **Kubernetes** (Pod Security Standards, Network Policies) и пишу правила Policy-as-Code на **Rego (Conftest)**.
- **Supply Chain Security:** настраиваю криптографическую подпись образов и аттестацию SBOM с помощью **Cosign (Sigstore)**.
- **Runtime Detection:** использую eBPF-инструменты (**Falco**) для мониторинга аномалий и защиты контейнеров (в т.ч. изоляцию через **Kata Containers**).
- **Vulnerability Management:** централизую, дедуплицирую и приоритизирую отчеты от SAST/DAST/SCA/IaC сканеров в **DefectDojo**, используя метрики CVSS и EPSS.
